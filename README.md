# nexus-kernel-enhanced

Enhanced NEXUS Kernel 2.0+ with advanced multi-agent orchestration, Bayesian-style reasoning, information theory, and comprehensive task simulations.

## What this repository contains

- `nexus_kernel_enhanced.py` — a stronger research-oriented kernel prototype with:
  - Bayesian-style evidence updates
  - multi-objective utility scoring
  - task-aware configuration tuning
  - safety gating and review thresholds
  - multi-agent trust-based fusion
  - dual-pool memory and learning
  - simulation across multiple real-world domains

- `nexus_kernel_benchmark.py` — a Monte Carlo benchmark harness that repeatedly evaluates the kernel across task profiles and operating modes.

- `test_nexus_kernel_enhanced.py` — deterministic validation checks for the core logic.

## Usage

Run the benchmark:

```bash
python nexus_kernel_benchmark.py
```

Run validation checks:

```bash
python test_nexus_kernel_enhanced.py
```

## Interpretation

The benchmark gives a far more meaningful view than a one-off demo because it reports:

- average reward
- success rate
- confidence level
- block rate
- review rate
- risk violations
- performance by task and config profile

This makes it useful for comparing conservative vs. balanced vs. aggressive policy settings.

## Current status

This remains a research-quality simulation rather than a production-grade autonomous system, but it is substantially more meaningful and testable than the original toy prototype.
